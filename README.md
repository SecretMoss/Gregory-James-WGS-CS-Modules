# Gregory James WGS CS Modules
This is my work for chapter two of the Wildcat Game Studios computer science modules.
As instructed, I have completed the game tutorial from Brackeys and then made my own changes to the game.

The changes I have made are as follows:
- Lowered the player speed and jump velocity to improve handling.
- Changed player hitbox from a circle to a rectangle to improve collision and jump detection when running off of ledges.
- Slightly modified the hitboxes of some of the bridge components so that the new player collision shape no longer gets stuck on them.
- The player's speed now gradually increases and decreases, and they will slow down much faster on the ground than if they are in the air.
- Increased the height of the moving platform and the coins above it. Also added a pause whenever the platform reaches either side of its path so the player has time to get on or off of it.
